# MU 3D Nexus R21 — Hybrid Combat Evolution ⚔️

Prototipo de combate 3D híbrido inspirado en MU Online, Solo Leveling y Zelda.

### Contenido de los archivos:
- `index.html`: Escena Three.js, personaje Dark Knight, enemigos (Goblin, Guerrero Caído), combate, barras de vida/maná y HUD de objetivo.
- `package.json`: Configuración de ejecución con Node.js (`npm start`).
- `server.js`: Servidor HTTP ligero para servir el juego en el puerto 8080.

### Cómo ejecutarlo en local:
```bash
npm start
# O con variable de entorno de puerto:
PORT=8080 node server.js
```
Abre `http://localhost:8080` en tu navegador.
